# ИС «Коммерческий центр» — Автоматизированная система управления закупками и анализа КП

Веб-приложение для комплексной автоматизации рабочего места менеджера отдела снабжения (коммерческого центра) промышленного предприятия (разработано на базе регламента закупочной деятельности ООО «Козельский механический завод»).

## Цель проекта

Оцифровка бумажного документооборота при проведении закупок материально-технических ресурсов (МТР), централизованный учет заказов и номенклатуры, исключение ошибок при расчете полной стоимости поставки и программный контроль соблюдения внутреннего регламента выбора поставщиков.

## Основной функционал и бизнес-процессы

Система охватывает полный цикл работы менеджера коммерческого центра — от поступления заявки до утверждения поставщика:

1. **Управление заказами (Задания на заказ):**
   * Регистрация и учет потребностей в МТР под конкретные производственные заказы.
   * Отслеживание статусов исполнения заявок и сроков поставки.
2. **Каталог и поиск товаров (Номенклатура МТР):**
   * Ведение справочника закупаемых материалов, комплектующих и оборудования.
   * Быстрый поиск позиций, просмотр истории закупок и привязка к поставщикам.
3. **База поставщиков (Каскадный подбор):**
   * Единый реестр контрагентов с контактными данными, реквизитами и историей работы.
   * Разделение поставщиков на три приоритетные категории согласно регламенту:
     1. *Производители*
     2. *Дистрибьюторы*
     3. *Дилеры*
4. **Сбор и контроль коммерческих предложений (КП):**
   * Привязка входящих счетов и КП к конкретным позициям заказа.
   * **Регламентная блокировка:** программный запрет на выбор победителя до тех пор, пока по позиции не будет собрано не менее 3 коммерческих предложений.
   * **Фиксация результатов торгов:** учет первоначальной цены и итоговой стоимости после переговоров о скидке с автоматическим расчетом суммы экономии.
5. **Анализ полной стоимости (МТР + ТЗР):**
   * Автоматический расчет итоговых затрат на закупку по формуле:
     \[\text{ИТОГО (руб.)} = \text{Стоимость МТР (руб.)} + \text{Транспортно-заготовительные расходы ТЗР (руб.)}\]
6. **Утверждение победителя и отчетность:**
   * Автоматическая подсветка наиболее выгодных предложений (по минимальной итоговой цене и оптимальным срокам поставки).
   * Утверждение выбранного поставщика и фиксация решения.
   * Генерация и выгрузка печатного бланка **«Отчет по работе с контрагентами»** (конкурентного листа).

## Стек технологий

* **Язык программирования:** Python 3.10+
* **Веб-фреймворк:** Django 5.x
* **База данных:** PostgreSQL 14+ (адаптер `psycopg` / `psycopg2-binary`)
* **Работа с документами и изображениями:** `openpyxl` (генерация отчетов в Excel), `Pillow` (загрузка и хранение сканов счетов и КП)
* **Фронтенд:** HTML5, CSS3 (адаптивные таблицы конкурентного листа и формы)

## Установка и запуск локально

1. **Клонировать репозиторий или перейти в папку проекта:**

   ```sh
   cd Commercial_centr
   ```

2. **Создать и активировать виртуальное окружение:**

   ```sh
   python -m venv .venv
   # Для Windows (CMD):
   .venv\Scripts\activate
   # Для Windows (Git Bash / Linux / macOS):
   source .venv/Scripts/activate
   ```

3. **Установить зависимости:**

   ```sh
   pip install -r requirements.txt
   ```

4. **Настроить базу данных PostgreSQL:**
   * Создайте пустую базу данных и пользователя в PostgreSQL (через `psql` или pgAdmin).
   * Укажите параметры подключения (`NAME`, `USER`, `PASSWORD`, `HOST`, `PORT`) в файле `commercial_center/settings.py` (или в файле переменных окружения `.env`).

5. **Применить миграции базы данных и создать администратора:**

   ```sh
   python manage.py migrate
   python manage.py createsuperuser
   ```

6. **Запустить сервер разработки:**

   ```sh
   python manage.py runserver
   ```

После запуска система доступна в браузере по адресу: `http://127.0.0` (панель управления: `http://127.0.0admin/`).
